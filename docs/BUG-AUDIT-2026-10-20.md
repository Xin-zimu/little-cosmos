**存档与进度**

**01 · [P1] 保存失败仍提示成功**　浏览器复现

- **触发与影响：** 模拟浏览器存储配额异常后，点击“保存进度”仍出现“进度已保存”。用户关闭游戏后会失去这次进度。
- **原因与位置：** save() 吞掉 setItem 异常，按钮回调不检查结果。 [src/main.js:477](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:477>)；[src/ui/ui.js:45](<D:/Deepseek WorkSpace/little-cosmos/src/ui/ui.js:45>)。
- **修复方向：** 让 save 返回成功/失败；仅成功时显示已保存，失败时保留当前状态并给出重试或导出入口。

**02 · [P1] 读档或重返星球会重置采集状态并重新随机资源**　浏览器复现

- **触发与影响：** 采集后保存，再加载同一星球，已采集节点数变为 0，原节点位置也改变。planetStates 实际保存为 {}；生物同样重新生成，死亡状态不保留。
- **原因与位置：** 星球加载直接重建资源与生物；planetStates 只有读写占位，没有捕获/恢复逻辑；资源坐标直接使用 Math.random。 [src/main.js:250](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:250>)；[src/main.js:475](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:475>)；[src/world/resources.js:89](<D:/Deepseek WorkSpace/little-cosmos/src/world/resources.js:89>)。
- **修复方向：** 给节点和生物稳定 ID，用星球种子生成固定布局，持久化采集冷却、死亡与必要动态状态，再在加载时恢复。

**03 · [P2] 合法 JSON 中的非法星球值会卡死继续游戏**　浏览器复现

- **触发与影响：** 隔离存档设为 planet:'bogus' 后继续，触发读取 biome 的 TypeError；starting=true、mode=intro、terrain=false，无法正常开始。
- **原因与位置：** 只捕获 JSON 解析异常；未验证 planet、bases 等结构，且先清掉当前场景再访问配置。 [src/main.js:389](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:389>)；[src/main.js:411](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:411>)；[src/main.js:191](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:191>)。
- **修复方向：** 读取后先做版本与结构校验，验证星球/建筑枚举与数值；成功验证后才替换场景，失败时清理 starting 并恢复菜单。

**04 · [P2] 飞行中可保存，但无法恢复当时的飞行**　代码确认

- **触发与影响：** 在太空、再入或下降阶段暂停保存，再继续只会回到地面探索，飞船位置、航向、油门、目标和阶段全部丢失。
- **原因与位置：** save 未序列化 FlightSystem；startGame 固定走 intro → surface，即使保存了 inRocket 也会被 beginExplore 清掉。 [src/main.js:460](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:460>)；[src/main.js:427](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:427>)；[src/ship/flight.js:42](<D:/Deepseek WorkSpace/little-cosmos/src/ship/flight.js:42>)。
- **修复方向：** 定义飞行检查点并保存/恢复必要状态；若暂不支持，应明确限制飞行中保存并说明恢复位置。

**05 · [P3] 存档没有保存实际观察方向**　代码确认

- **触发与影响：** 转动视角后保存再继续，视角会重置到角色身后与固定俯仰，不能恢复保存时的镜头。
- **原因与位置：** 保存的是不存在于控制逻辑中的 p.pitch，而真实字段是 camPitch/camYaw；beginExplore 又覆盖镜头参数。 [src/main.js:492](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:492>)；[src/main.js:427](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:427>)；[src/player/controller.js:55](<D:/Deepseek WorkSpace/little-cosmos/src/player/controller.js:55>)。
- **修复方向：** 保存并校验 camYaw/camPitch，在读档与新游戏中分别初始化镜头，避免统一覆盖。

**10 · [P1] 带触屏的电脑可能完全无法用鼠标转视角**　代码确认

- **触发与影响：** 设备报告 maxTouchPoints>0 时，即使用户使用鼠标、屏幕很大且触摸 UI 未显示，requestLock 仍直接返回；mousemove 又要求 locked 才处理。

- **原因与位置：** 通用触摸按钮只监听 touchstart/touchend，未处理 touchcancel。 [src/ui/ui.js:62](<D:/Deepseek WorkSpace/little-cosmos/src/ui/ui.js:62>)；[src/core/input.js:99](<D:/Deepseek WorkSpace/little-cosmos/src/core/input.js:99>)。

- **触发与影响：** 设置瞄准、待处理 Space 和 mouseDX=100 后触发 blur，三者均残留；切回游戏可能持续瞄准、额外跳跃或突然转头。

**13 · [P2] 暂停期间按键会在恢复时补执行**　浏览器复现

**性能、音频与界面**

**43 · [P2] 切换星球没有完整释放 GPU 资源**　浏览器复现

- **触发与影响：** 监听旧地形材质和旧水面几何的 dispose，切换后调用次数均为 0；同一星球连续重载四次，renderer.info.memory.textures 为 19→20→21→22。长期往返存在资源持续增长。
- **原因与位置：** clearPlanet 多处只 remove，地形/植被也主要只释放 geometry；建筑 clear 不释放几何材质，灯光阴影等资源未统一回收。 [src/main.js:168](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:168>)；[src/base/building.js:474](<D:/Deepseek WorkSpace/little-cosmos/src/base/building.js:474>)。
- **修复方向：** 实现各系统 dispose，按所有权释放几何、材质、纹理、阴影目标及自定义材质；共享资源去重处理。

**44 · [P2] 切低画质后后期仍按高像素比渲染**　浏览器复现

- **触发与影响：** 低画质 rendererPixelRatio=1，但 composerPixelRatio=1.4；画布 1250×705，后期目标仍约 1750×987，像素量接近两倍，降低画质的性能收益被抵消。
- **原因与位置：** 只更新 renderer 的 pixel ratio，EffectComposer 保留构造时的值；resize 没有同步 composer.setPixelRatio。 [src/core/engine.js:111](<D:/Deepseek WorkSpace/little-cosmos/src/core/engine.js:111>)；[src/core/engine.js:138](<D:/Deepseek WorkSpace/little-cosmos/src/core/engine.js:138>)；[src/core/engine.js:149](<D:/Deepseek WorkSpace/little-cosmos/src/core/engine.js:149>)。
- **修复方向：** 统一渲染器、后期链和 bloom 的尺寸/像素比更新顺序，并避免逻辑尺寸与物理像素重复相乘。

**45 · [P2] 离开太空后引擎持续嗡鸣**　浏览器复现

- **触发与影响：** 启用引擎音后切回地表音景，1.5 秒后引擎 gain 仍约 0.215；降落完成和返回菜单都没有将它关闭。
- **原因与位置：** setEngine 只在太空更新中调用，其他阶段没有把引擎层目标增益归零；setPlanet 只调整风与空气声。 [src/ship/flight.js:362](<D:/Deepseek WorkSpace/little-cosmos/src/ship/flight.js:362>)；[src/core/audio.js:417](<D:/Deepseek WorkSpace/little-cosmos/src/core/audio.js:417>)；[src/core/audio.js:434](<D:/Deepseek WorkSpace/little-cosmos/src/core/audio.js:434>)；[src/main.js:817](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:817>)。
- **修复方向：** 在飞行阶段切换中统一设置引擎目标音量，地表/菜单明确淡出为 0。

**46 · [P2] 音乐和音效都设为零仍有环境声与引擎声**　浏览器复现

- **触发与影响：** 两个滑块均设为 0 后，musicBus/sfxBus 为 0，但 ambBus 仍是 0.8，引擎仍有非零 gain。
- **原因与位置：** 环境声走独立 ambBus，引擎直接接 master，均绕过音效滑块。 [src/core/audio.js:56](<D:/Deepseek WorkSpace/little-cosmos/src/core/audio.js:56>)；[src/core/audio.js:411](<D:/Deepseek WorkSpace/little-cosmos/src/core/audio.js:411>)；[src/core/audio.js:543](<D:/Deepseek WorkSpace/little-cosmos/src/core/audio.js:543>)。
- **修复方向：** 将环境和引擎接入受控音效总线，或提供明确的环境/主音量设置；零音量行为应一致。

**47 · [P2] 长时间暂停后音乐调度追赶旧时间**　代码确认

- **触发与影响：** 暂停时 AudioContext 时间继续推进，nextNoteTime 不更新；恢复后 updateMusic 每帧只向前推进约一拍，会连续安排已在过去的音符，造成静音、节奏突变或追赶。具体听感随浏览器而异。
- **原因与位置：** 游戏时钟暂停与音频时钟不同步，调度器没有丢弃过期的音乐事件。 [src/main.js:833](<D:/Deepseek WorkSpace/little-cosmos/src/main.js:833>)；[src/core/audio.js:456](<D:/Deepseek WorkSpace/little-cosmos/src/core/audio.js:456>)；[src/core/audio.js:497](<D:/Deepseek WorkSpace/little-cosmos/src/core/audio.js:497>)。
- **修复方向：** 恢复时把 nextNoteTime 重新对齐 currentTime；或者暂停音频上下文，并用有上限的前瞻调度。

**48 · [P3] 进入自由探索后任务栏还显示旧进度**　浏览器复现

- **触发与影响：** 先显示 0/1 的目标，再 setObjective(null)，标题变成“自由探索”，计数仍为 0/1、进度条仍为 0%。

- **修复方向：** 无目标时清空或隐藏进度区；设新目标时统一初始化文本和进度。
